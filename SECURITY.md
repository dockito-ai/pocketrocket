# Security policy

To report a vulnerability in PocketRocket, please do it privately: open a
[private security advisory](../../security/advisories/new) on this repository
(Security tab, "Report a vulnerability"). Please don't open a public issue for it.

PocketRocket is a personal project maintained by one person, so there is no
service level, but reports are read and taken seriously.

Problems in Claude Code itself belong with Anthropic. Problems in Termux's own
code that aren't specific to PocketRocket belong with the
[Termux project](https://github.com/termux/termux-app).
