## Notes

- Everything except MongoDB and .NET has a current Termux package, so cause C (glibc) is not needed for this group. Termux packages are the first choice per the sweep plan, and nothing here needs the glibc loader.
- Biggest installs: Zig 407 MB, .NET ~311 MB, Java 249 MB, Go 224 MB (plus clang), MariaDB 196 MB, Erlang+Elixir ~138 MB. Good candidates for add-on tiles, not the base set. Python (26 MB + pip 7 MB, plus uv 34 MB) is the only small widely-needed language.
- Servers (PostgreSQL, Redis, MariaDB): no systemd or init, so the tile or recipe must create the data dir and start the process itself; processes die when Android kills the app unless keepalive is on. Ports above 1024 only.
- `/tmp` (cause B): PostgreSQL, MariaDB, tmux and Python all honour `$TMPDIR` (`$PREFIX/tmp`) in Termux builds; third-party downloaded tools may not (inferred).
- Kotlin and Maven/Gradle all depend on a JDK. JDK 17 is already on this phone, so Kotlin's `openjdk-21` dependency would add a second JDK unless alternatives are satisfied (check `apt-cache policy` before choosing).
- .NET is the only one I'd call uncertain: package exists but runtime reliability on arm64 Android has failure reports that I could not confirm as fixed. Needs a real probe (`dotnet new console`, `dotnet run`).
- Unverified: package contents (e.g. whether `python` includes venv and ensurepip, which it normally does), transitive dependency sizes (Go's clang, ffmpeg's libs, httpie's python libs) and server start-up behaviour. These are inferred from Termux conventions.
