# UX mockup

Source of the clickable mockup Shankar approved on 29 Oct 2026 (https://claude.ai/artifact/2D6p4ZE35mGKA1PSfKzAyG). One file per screen; read the markup for layout, copy and states. Sample data is made up. The real app follows this look: dark first, navy/orange, Inter + JetBrains Mono, 24 px side padding, quiet cards, status colours (amber needs you, blue working, green done, red error, grey paused).

Screens: Main (Home: sessions with project tabs), Session, Controls, NewSession, Workspaces, Clone, Workspace, Git, Diff, Browse, Settings, ClaudeAccounts, ClaudeAccount, GitHubAccounts, NewWorkspace, WorkspaceSettings.

`BranchesPRs.html` (29 Oct 2026, plain HTML in this style): branches, graph and pull requests in the Git screen (decision 27).

`Attachments.html` (29 Oct 2026, plain HTML drawn in this style, not from Claude Design): the composer "+" sheet, attachment tray, sent message and Share to PocketRocket. Option A is the approved one (decision 24).

`Settings.dc.html` was redrawn on 31 Oct 2026 for decision 88: ACCOUNTS, DEVELOP, ROCKET, THIS PHONE and APP, every item one card.

`Backup.dc.html` (31 Oct 2026, plain HTML in this style): Settings › Backup, back up and restore in every state (decision 53).

`BackgroundTasks.html` (31 Oct 2026, plain HTML in this style, with buttons that stand in for Claude Code's events): background Bash cards, the counts beside the mode, the Background sheet, a shell's output screen, Move to background, the End session warning and the service notification (decision 69).
