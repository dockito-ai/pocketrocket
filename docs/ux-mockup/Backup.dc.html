Notes for the build

  • Settings row: under APP, after Updates. The page is full screen with no bottom nav, like Updates.
  • It only backs up. There is no uninstall button, and Welcome and first-run setup don't change.
  • The flow Shankar uses: reinstall, first-run setup, sign in, then Settings › Backup › Restore by hand. Nothing restores itself.
  • Notification: "Backing up dockito-api · 42%" with a bar and Cancel, then "Backed up" or "Couldn't back up". Same for restore.
  • Steps use StepList's compact style, as Updates does. Passphrases are never saved, logged or put in an intent.
