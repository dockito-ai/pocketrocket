Attachments in the session chat

Draft for Shankar. Three ways to fit attach into the composer without making it more crowded, then what an attached message looks like and the share-to flow. The composer today is: / · Message field · Mic, with the status line under it.

Option A: "+" replaces "/" my pick

The left button becomes "+". It opens one sheet with Photos, Files, Camera and Commands. Typing "/" in the field still opens the command picker, so nothing is lost. The composer keeps exactly three things in a row.

Option C: long-press "/"

No visible change at all: tap "/" for commands, long-press it for attach. Cleanest, but nobody finds a long-press, including you in three weeks. Listed so you can rule it out.

With attachments (any option)

A tray appears above the field only while something is attached, so the empty composer never grows. Images show as thumbnails, other files as a chip with name and size. ✕ removes one. Mic turns into Send once there is text or an attachment.

Share to PocketRocket from another app

From Gallery, Files, Chrome or WhatsApp: Share → PocketRocket. A sheet asks which session; the one that needs you or was used last is first. "New session" asks for the project.
