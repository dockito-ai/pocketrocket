Updates

Settings → Updates (decision 41). One page for everything PocketRocket keeps current: PocketRocket itself, Claude Code, Git and Dockito. Full screen with no bottom nav, the same as Tools. Each row shows the installed version and either "Up to date" or "Update to X". A running update shows its steps and live progress the same way a tool page does. Sample data is made up.
